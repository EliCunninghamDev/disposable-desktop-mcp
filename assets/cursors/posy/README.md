# Posy cursor asset

`left_ptr-32.png` is the 32 px `left_ptr` cursor extracted from
`Posy_Cursor/cursors/default` in
[simtrami/posy-improved-cursor-linux](https://github.com/simtrami/posy-improved-cursor-linux)
at commit `ffef15950490af620fd0f70cc98847880f63d96e`.

The cursor design is by Michiel de Boer (Posy), and the Linux port is by
simtrami. Both are licensed under the
[Creative Commons Attribution-NonCommercial 4.0 International License][cc-by-nc]
(CC BY-NC 4.0); see [`LICENSE`](LICENSE).

This asset is **not** MIT-licensed like the rest of `xephyr-mcp`. It is
embedded in the binary and used to draw the pointer in screenshots and the
viewer. Commercial redistributors must remove or replace it with an asset they
have the right to use.

The 32 px Xcursor image was converted to PNG without scaling. Its hotspot is
the top-left pixel `(0, 0)`, matching the source cursor.
